Personalized Bluefin I plan to use on my ThinkPad.

Based on Bluefin stable

In order to use this you have to:
- Install Bluefin or Bazzite GNOME

then run this command: ```sudo bootc switch ghcr.io/badwolf292/thinkos-gnome```


The current extra packages I have added are:
- android-tools (adb)
- jotta-cli (CLI tool for Jottacloud)
- nmap
